# Track setup and changing sounds

## Select the destination first

Hold **PAD BANK** and press pad 1–16 to select the track. Press **PAD FX + KNOB FX** together to open the **Mixer**. Turn the encoder or press a track pad to select it.

## Change an instrument or track type

1. On the track screen or Mixer, hold the encoder to open **MENU**.
2. Choose **HERE → TRACK SETUP**, then push the encoder.
3. Choose **CHANGE PLUG-IN** to replace the current plug-in, or **TRACK TYPE** to choose another type.
4. Select the instrument or type. The track's existing patterns stay in place.

The Mixer retains Melodee's native **B1 SENDS / FX**, **B2 EQ** and **B3 COMP** controls. TRACK SETUP does not replace these buttons. On a track's separate FX page, **B2 TRACK SETUP** is an additional route; bus, submix and master FX retain their own controls.

## EMPTY track versus an empty sample pad

An EMPTY track shows the native type choices. Push the encoder to continue with the selected type. An intentionally empty track uses the same choices.

A Sample Kit is already a track type. On its SOUND or TRIM page, pushing the encoder on an empty pad opens **SAMPLES** for that pad, even if every pad in the kit is empty. Choose a file and push to load it. This does not change the track type.

## Delete separately

In **TRACK SETUP**, **DELETE TRACK** removes the instrument and all of its patterns after confirmation. To change an instrument while keeping its patterns, use **CHANGE PLUG-IN** or **TRACK TYPE** instead. **UNDO** restores a completed change or deletion.

## Switching tracks while browsing

Changing the selected track closes the previous track's preset/load view and follows the newly selected track. A load already in progress keeps its original destination. It is cancelled if that destination is replaced or deleted; it cannot land on a different selected track.

## Back and cancel

**SHIFT + encoder push** goes back one level. While MENU is open it closes MENU without selecting an action. In a confirmation it cancels. In a source or destination browser it returns to its caller according to that browser's displayed BACK button.

## Sends in BASIC mode

In the Mixer, **B1 SENDS** stays visible in BASIC mode. It offers **ENABLE FULL** to reach all four sends and the advanced mixer controls. **CANCEL** or **SHIFT + encoder push** retains BASIC mode and leaves the project unchanged. In FULL, B1 switches between SENDS and FX; the second send row includes send D.
